Odzyskiwanie

Każdą zmianę można cofnąć.

Instalator nigdy nie zakłada, że obecna konfiguracja jest niepotrzebna.

Gdzie znajdują się kopie?

~/.local/state/arch-pl-os/kopie/

Każda instalacja tworzy nowy katalog oznaczony datą i godziną. Kopie nie są nadpisywane.

Przywrócenie ostatniej konfiguracji

cd ~/arch-pl-os
./przywroc.sh

Skrypt zatrzymuje komponenty ARCH PL OS, odtwarza wcześniejsze pliki i przeładowuje Hyprland.

Przywrócenie wybranej kopii

./przywroc.sh ~/.local/state/arch-pl-os/kopie/20260822-120000

Zastąp przykładową datę nazwą istniejącego katalogu.

Gdy środowisko graficzne się nie uruchamia

  1. Przejdź do konsoli skrótem Ctrl + Alt + F3.
  2. Zaloguj się na swoje konto.
  3. Wejdź do katalogu repozytorium.
  4. Uruchom ./przywroc.sh.
  5. Wróć do ekranu logowania lub uruchom ponownie komputer.
Ważne: skrypt nie dotyka dokumentów, zdjęć, projektów, kluczy SSH ani danych przeglądarki.

Ponowna instalacja

Jeśli chcesz wrócić do ARCH PL OS po przywróceniu, uruchom ponownie ./instaluj.sh. Instalator jest idempotentny i może być używany wielokrotnie.
