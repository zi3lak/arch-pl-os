Poradnik instalacji

Od czystego Arch Linux do polskiego pulpitu.

Każdy krok opisany jasno, bez pomijania warunków i bez zgadywania.

1. Zanim zaczniesz

Potrzebujesz działającego Arch Linux, połączenia z internetem, zwykłego konta użytkownika z dostępem do sudo oraz uruchomionej sesji Hyprland. Instalator nie usuwa Twoich plików osobistych.

Bezpieczeństwo: przed zmianą konfiguracji instalator automatycznie zapisuje kopię Hyprland, Waybar, Wofi, Alacritty, Dunst i ustawień GTK.

Sprawdź połączenie z internetem

ping -c 3 archlinux.org

Zaktualizuj system

sudo pacman -Syu

2. Zainstaluj Git

sudo pacman -S --needed git

Git pobierze kod projektu i pozwoli później aktualizować system jednym poleceniem.

3. Pobierz ARCH PL OS

git clone https://github.com/zi3lak/arch-pl-os.git
cd arch-pl-os

4. Najpierw wykonaj próbę

./instaluj.sh --proba

Tryb próbny pokazuje katalog docelowy oraz brakujące pakiety. Nie modyfikuje żadnego pliku.

5. Uruchom instalację

./instaluj.sh

Instalator doinstaluje pakiety, wygeneruje polskie locale, wykryje monitory, utworzy kopię konfiguracji i zastosuje pulpit.

Nie przerywaj: generowanie locale i instalacja pakietów mogą potrwać kilka minut.

6. Sprawdź rezultat

./sprawdz.sh

Każdy element powinien otrzymać status [DOBRZE]. Jeśli pojawi się błąd, przeczytaj nazwę elementu i uruchom ponownie instalator.

7. Uruchom ponownie sesję

Pełny efekt zmiennych językowych będzie widoczny po wylogowaniu i ponownym zalogowaniu. Nie musisz restartować całego komputera.

Opcje zaawansowane

  • ./instaluj.sh --bez-pakietow — nie uruchamia Pacmana.
  • ./instaluj.sh --bez-locale — nie zmienia konfiguracji języka systemowego.
  • ./przywroc.sh — wraca do poprzedniego pulpitu.
