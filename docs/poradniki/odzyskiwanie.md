# Kopie i odzyskiwanie

Każda instalacja tworzy kopię w:

```text
~/.local/state/arch-pl-os/kopie/
```

Przywrócenie ostatniej kopii:

```bash
./przywroc.sh
```

Przywrócenie konkretnej kopii:

```bash
./przywroc.sh ~/.local/state/arch-pl-os/kopie/RRRRMMDD-GGMMSS
```

W razie problemu z sesją graficzną użyj `Ctrl+Alt+F3`, zaloguj się i uruchom skrypt z konsoli.
